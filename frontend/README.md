# ClearSpec AI - Frontend

React + Vite + Tailwind CSS interface for ClearSpec AI export regulatory compliance engine.

## Features
- **Unit Normalizer & BLQ Trap Validator**: Interactive conversion to canonical `mg/kg` and one-click test suites for the "BLQ > MRL Trap".
- **EU MRL & CAS Registry Lookup**: Automatic 8-digit HS normalization to 4-digit prefixes and CAS/alias chemical lookups.
- **2026 EU CBAM Fastener Calculator**: Validates complex goods fastener exports (CN 731815) against precursor wire rod (CN 7213) verification rules.

## Local Development
```bash
npm install
npm run dev
```
